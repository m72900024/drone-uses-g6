# 四軸無人機教學｜國小六年級

國小六年級自然課用的四軸無人機教學網站。課程從「無人機可以做什麼」開始，銜接自然課的作用力與反作用力，再進到四軸馬達配置、控制原理與互動模擬。

網站：<https://m72900024.github.io/drone-uses-g6/>

## 課程內容

- 第一堂：無人機的運用
  - 無人機種類
  - 六大生活運用總覽
  - 空拍、農業、救災、物流、巡檢、燈光秀案例影片
- 第二堂：飛行原理
  - 作用力與反作用力
  - 直升機升力與反扭矩
  - 四軸如何用兩兩相反的馬達抵消反扭矩
  - 直升機反扭矩實驗室與四軸組裝練習場
- 第三堂：四軸控制
  - 上升下降、前進後退、左右側移、偏航
  - 四顆馬達轉速如何造成不同飛行動作
  - 馬達轉速實驗室與 LOS 飛行模擬器

## 技術說明

這是純靜態網站，不需要建置流程或套件安裝。所有頁面可直接由 GitHub Pages 部署。

- HTML + CSS + 原生 JavaScript
- 共用樣式：[assets/style.css](assets/style.css)
- YouTube 影片採點擊後載入：[assets/play.js](assets/play.js)
- 互動實驗室各自寫在單一 HTML 檔內，方便教學與部署

## 本機預覽

可以直接打開 `index.html`，或用簡單的本機伺服器預覽：

```bash
python3 -m http.server 8000
```

再開啟：

```text
http://localhost:8000/
```

## 授課建議

- 第一堂適合用來建立動機，讓學生知道無人機不是只有空拍。
- 第二堂可搭配自然課「作用力與反作用力」，用氣球、水火箭、螺旋槳逐步銜接。
- 第三堂建議讓學生先玩馬達轉速實驗室，再進 LOS 飛行模擬器。
